# Valentina Zvereva — Academic Website

Static academic website for Valentina Zvereva, designed in a clean GitHub Pages style.

## GitHub Pages

This repository can be published from the `main` branch and repository root in **Settings → Pages**.

Because the repository is named `zvereva-valentina.github.io` rather than `Takaya-Valya.github.io`, GitHub treats it as a project site. Its default URL is:

`https://takaya-valya.github.io/zvereva-valentina.github.io/`

To use the root URL `https://takaya-valya.github.io/`, rename the repository to `Takaya-Valya.github.io`.

The `.nojekyll` file is intentional and keeps GitHub Pages from applying Jekyll processing.
